# Minsky — Marketing Hub

Plataforma interna centralizada para el equipo de marketing.

## Módulos

1. **IA Add-ons**
2. **Chat**
3. **Calendario**
4. **Kanban**
5. **Streaming**
6. **Activos**

## Inicio rápido

1. Clonar el repositorio.
2. Copiar `.env.local.example` a `.env.local` y rellenar las variables de Supabase.
3. Instalar dependencias: `npm install`
4. Ejecutar las migraciones en tu proyecto de Supabase usando el CLI de Supabase o la interfaz web (el archivo está en `supabase/migrations/001_initial_schema.sql`).
5. Iniciar el servidor de desarrollo: `npm run dev`
6. Abrir [http://localhost:3000](http://localhost:3000) en tu navegador.
